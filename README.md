# Faro — Rastreador de Hábitos

App web de una sola página para marcar hábitos diarios, ver tu racha (streak) y un mapa de calor estilo GitHub de los últimos ~3 meses.

## Uso

Abre `index.html` en tu navegador. No requiere instalación ni servidor.

## Datos

Todo se guarda localmente en el navegador (`localStorage`). No hay backend ni sincronización entre dispositivos.
